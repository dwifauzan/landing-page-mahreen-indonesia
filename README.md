# Mahreen Indonesia Landing Page - "Berkarya Untuk Indonesia"

Landing Page premium yang dirancang untuk program Internship Mahreen Indonesia. Proyek ini dibangun dengan pendekatan **Spec-Driven Development** dan mengadopsi estetika desain agensi digital kelas dunia (Axion Studio).

## 🚀 Fitur Utama

- **Premium Visual Storytelling:** Desain minimalis dengan tipografi dramatis dan ruang negatif yang terukur.
- **Dynamic Hero Section:** Latar belakang "Shader-like" yang menggabungkan citra halus dengan animasi gradien CSS.
- **Asymmetric Editorial Grid:** Layout grid tidak simetris pada desktop untuk memberikan ritme visual yang menarik.
- **Micro-Interactions:**
  - **Text-Roll Animation:** Efek gulungan teks vertikal pada tombol CTA.
  - **Expanding Pill Button:** Tombol yang melebar secara dinamis saat kartu program di-hover.
  - **Rotating Arrows:** Ikon indikator arah yang berputar mulus saat interaksi.
- **Tech-Savvy Navbar:** Dilengkapi jam real-time (WIB) Jakarta dan sistem navigasi melayang (*floating pill*).
- **SEO Optimized:** Sudah dilengkapi Title tag dinamis, Meta Description, dan Keywords strategis.
- **Fully Responsive:** Optimasi untuk Mobile, Tablet, hingga Desktop (Max 1440px).

## 🛠 Tech Stack

- **Core:** HTML5 (Semantic).
- **Styling:** Tailwind CSS v3.4 (via CDN).
- **Fonts:** Inter (Google Fonts).
- **Logic:** Vanilla JavaScript (ES6+).
- **Assets:** Unsplash CDN (Optimized via URL parameters).

## 📖 Cara Menjalankan

1. Pastikan Anda memiliki koneksi internet (untuk memuat library via CDN).
2. Buka file `index.html` menggunakan browser favorit Anda (Chrome, Safari, Edge, atau Firefox).
3. Untuk pengalaman pengembangan yang lebih baik, gunakan ekstensi **Live Server** di VS Code.
